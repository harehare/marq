# Welcome to the demo vault

This vault is the sample for [Marq](https://github.com/harehare/marq). Everything in it is a Markdown file, and the agents work on a small project, `taskly`.

## Try these

1. Open [[Design: taskly]], hover the **Open questions** heading and choose **Ask**.
2. Open the request [[Fix "in N days" due dates]] and run it. The agent works in its own git worktree; review the diff in **Changes**.
3. Open the **Sprint** board and drag a card.
4. Open **Query** and run the presets over `requests/*.md`.

## Terms

The vault's [[glossary]] makes a search for *deadline* find notes about *due date*.
